# metaphlanToPhyloseq: Convert MetaPhlAn taxonomic profiles to phyloseq objects

Simple package to load MetaPhlAn taxonomic profiles, clean or filter
them based on specified taxonomic rank or abundance threshold, and
create a phyloseq object from them.
